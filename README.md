# Brenda’s Portfolio — HW5

## Cat Facts Widget

I first added a Cat Facts widget to my Technical Projects page
so visitors can discover a random cat fact without leaving the page.

When you click Next fact, the widget will says “loading a cat fact…” and
requests a fact from the Cat Facts API. If the response is successful and
contains fact text, the widget updates the paragraph and says “new cat fact!”
If something goes wrong, the current fact stays visible and then a message will ask you to try again.

The Pink border button allows you to be able to turn the border on or off. I used
localStorage to remember that choice when you refresh the page.
